# librox.app

The published site for [Librox](https://librox.app), served by GitHub Pages
from the root of `main`.

These files are build output. The source is the `website/` directory of the
Libros repository (an Astro project); this build is from commit
`12293580bef9b816ad4a5eb7984b8fe5b598e131`. To change the site, edit the source, run `npm run build` there,
and replace the files here with the contents of `dist/`.

Addresses the app depends on, which must keep working:

- `/privacy.html`, `/terms.html`, `/support.html`
- `/feeds/discover-seed.json`

The previous site, with its film sources, is kept at the tag
`archive/site-2026-10`.
